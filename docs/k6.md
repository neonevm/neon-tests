# K6 Performance Testing

K6 is used for load testing and performance benchmarking of Neon EVM and Proxy components.

## Prerequisites

- **Golang** >= 1.19
- Add Golang to your PATH:
  ```bash
  export PATH=$PATH:$(go env GOPATH)/bin
  ```

## Quick Start

### 1. Build K6 with Ethereum Plugin

Install xk6 and build an executable file with Neon's forked Ethereum plugin:

```bash
./clickfile.py k6 build --tag 05e0ce5
```

The `--tag` parameter specifies the version of neonlabsorg's forked xk6-ethereum plugin (can be a fixed version or commit SHA).

### 2. Run Performance Test

```bash
./clickfile.py k6 run --network devnet --script ./loadtesting/k6/tests/sendNeon.test.js --users 100 --balance 200
```

This command will:
- Compile and deploy smart contracts
- Prepare test accounts with specified balances
- Run the specified load test script

## Available Commands

### Build Command
```bash
./clickfile.py k6 build [OPTIONS]
```

**Options:**
- `-t, --tag` - Ethereum plugin tag or commit SHA (default: `05e0ce5`)

### Run Command
```bash
./clickfile.py k6 run [OPTIONS]
```

**Options:**
- `-n, --network` - Network to use (required, e.g., `local`, `devnet`)
- `-s, --script` - Path to k6 script (required, default: `./loadtesting/k6/tests/sendNeon.test.js`)
- `-u, --users` - Number of users to generate (required)
- `-b, --balance` - Initial balance of accounts in Neon (required)
- `-a, --bank_account` - Ethereum bank account private key (optional)

### Get Help
```bash
./clickfile.py k6 --help
```

## Advanced Usage

### Native K6 Commands

If you prefer to use K6 directly without clickfile.py:

**Install xk6:**
```bash
go install go.k6.io/xk6/cmd/xk6@latest
```

**Build K6 binary:**
```bash
xk6 build --with github.com/szkiba/xk6-prometheus --with github.com/neonlabsorg/xk6-ethereum@${BUILD_TAG}
```

**Run test:**
```bash
./k6 run -o 'prometheus=namespace=k6' -e K6_USERS_NUMBER=100 -e K6_INITIAL_BALANCE=200 ./loadtesting/k6/tests/sendNeon.test.js
```

### Local Plugin Development

For testing local changes to the xk6-ethereum plugin:

```bash
xk6 build --with github.com/szkiba/xk6-prometheus --with github.com/neonlabsorg/xk6-ethereum="<path_to_local_xk6_ethereum_repository>"
```

### Scenario Configuration

K6 scenarios use ramping VUs executor with the following standard configuration:

```javascript
export const standardScenarioOptions = {
    scenarios: {
        standardScenario: {
            executor: 'ramping-vus',
            startVUs: 0,
            stages: [
                { duration: '30s', target: usersNumber },
                { duration: '1200s', target: usersNumber },
            ],
            gracefulRampDown: '60s',
        },
    },
    noConnectionReuse: true,
};
```

## Tracer Load Testing

### Data Preparation

Prepare test data for tracer load tests:

```bash
cd scripts/tracer_load_preparation
python3 -m tracer_data_producer.py
```

**Required environment variables:**
- `NETWORK`
- `BANK_ACCOUNT_PRIVATE_KEY` (if needed)
- `TRANSFERS`
- `CONTRACT_CALLS`
- `ITERATIVE_TXS`

### Run Tracer Tests

```bash
./clickfile.py k6 run --network local --script loadtesting/k6/scenarios/tracerStandardLoad.js --users 10 --balance 200
```

## Troubleshooting

### Common Issues

1. **Golang not in PATH**
   ```bash
   export PATH=$PATH:$(go env GOPATH)/bin
   ```

2. **Permission denied when running k6**
   ```bash
   chmod +x ./k6
   ```

3. **Plugin build failures**
   - Check Golang version (>= 1.19 required)
   - Verify network connectivity for downloading dependencies
